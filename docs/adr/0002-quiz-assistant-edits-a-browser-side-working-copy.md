# The quiz assistant edits a browser-side working copy; only Save writes

The quiz assistant changes a quiz through client tools that edit a working copy held in the browser, checked by the quiz validator after every change; only an explicit Save (validated again on the server, with a confirm when it removes questions that carry flags or attempts) writes to the database. We rejected letting the model write to the database as it goes, which would leave half-built quizzes behind and delete users' flags and attempts without their say, and server tools over a server-held working copy, which would need conversation state on the server for no gain. The model reaches the web only through the providers' own search and fetch tools, never through a fetcher on our server, so it cannot be steered at internal addresses. The cost: neither the conversation nor unsaved changes survive a reload, and OpenAI reads a given URL less reliably than Claude.
